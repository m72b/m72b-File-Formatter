Documentation & Tutorial
1. Load files
Pick a folder or select individual files. The original extension is kept automatically when a new name does not include one.

2. Build a template
Enter a format such as {TrackNumber} - {TrackName} - {Artist}.{ext}. Click a token chip to insert it, or add your own token and provide its value under Token Overrides.

3. Apply and save
Apply the format, edit rows directly, then use Save or Save All. Revert removes unsaved changes.

4. Filename rule
The left-panel rule can look for any phrase, such as like, and rename only matching files to your chosen new base name, such as like 2. The extension stays unchanged.

5. Organizer
Open the File Organizer tab from the header button — the screen slides across. Choose a source folder, then add rules: a filename pattern (e.g. *.mp3), a modified-year range (e.g. 2020–2021, or just "up to 2020"), or a file-size range (e.g. 100MB–2GB, or just "500MB and up") — each pointing to a destination subfolder. Preview first, then run.
